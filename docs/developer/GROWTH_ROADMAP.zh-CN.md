# NotionNext 可持续增长路线图

这份路线图只解决一个问题：如何让更多人更快成功上线，并愿意把自己的经验、站点和改进反哺给社区。

NotionNext 的增长不应先依赖复杂平台能力。更短路径是把现有开源项目打磨成一个清晰飞轮：

```text
新用户看懂价值 -> 20 分钟上线 -> 提交站点案例 -> 案例帮助下一批用户选型 -> 重复问题沉淀成文档和小 PR
```

## 北极星指标

优先看这些信号，而不是先追求功能数量：

| 指标 | 说明 |
| --- | --- |
| 新用户首站成功率 | 用户能否按文档完成复制模板、Fork、部署和填写环境变量 |
| 从进入文档到上线时间 | 新手是否能在 20-30 分钟内看到可访问站点 |
| Showcase 提交数 | 有多少真实站点愿意公开展示 |
| 重复问题文档化率 | 高频 Issue / Discussion 是否被沉淀为 FAQ 或教程 |
| 首次贡献路径 | 新贡献者是否能从文档、截图、主题说明等低风险任务开始 |

## 90 天计划

### Phase 1: 统一入口叙事（第 1-2 周）

目标：任何人打开仓库或文档站，都能马上知道 NotionNext 是什么、适合谁、下一步做什么。

最小任务：

1. 重写英文 README，使它和中文 README 的定位一致。
2. 清理 Vercel 部署页中的旧个人化措辞和旧仓库链接。
3. 把“开始搭建 / 主题全览 / Showcase / 支持”做成稳定入口。
4. 保留旧版手册链接，但降低它在新手路径中的权重。

验收：

- README 中英文都能回答：用它做什么、谁适合、怎么开始、哪里看案例。
- 部署页不再出现“复制我的代码”这类个人站长口吻。
- 新用户不需要在多个旧入口之间判断哪篇才是最新教程。

### Phase 2: 建立 Showcase 飞轮（第 3-4 周）

目标：把真实用户站点变成最轻量的传播资产。

最小任务：

1. 新增 Showcase 页面，公开征集用户提交已上线站点。
2. 收集字段只保留：站点名、链接、用途、主题、提交人。
3. 在 README、文档首页、主题目录和支持页加入 Showcase 入口。
4. 在 GitHub Discussions 准备“提交你的站点”置顶帖。

验收：

- 用户能在 1 分钟内找到案例页面。
- 用户知道如何提交自己的站点。
- 每个案例能反向帮助新用户选择主题。

### Phase 3: 模板驱动上手（第 5-8 周）

目标：让用户复制结果，而不是阅读大量配置。

最小任务：

1. 梳理 5 个官方 Notion 模板入口：博客、知识库、作品集、产品官网、导航站。
2. 每个模板只配一条推荐主题路径。
3. 为每个模板写一页“适合谁 / 复制后改哪几处 / 推荐主题”。
4. 把模板入口放进开始页和主题目录。

验收：

- 新用户可以按目标直接选模板。
- 模板文档不讲所有配置，只讲上线必须改的字段。
- 每个模板能对应到 Showcase 里的真实案例。

### Phase 4: 社区维护转化（第 9-12 周）

目标：把重复支持成本变成社区资产。

最小任务：

1. 每周从 Issue / Discussion 中整理 3-5 个重复问题。
2. 能写文档就写文档，能标 good first issue 就标 issue。
3. 支持页改成“免费支持 / 付费协助 / 赞助项目”三段。
4. 新贡献者优先从文档、截图、主题说明、FAQ 小修开始。

验收：

- 支持页不再像私人付费页，而是清楚分流。
- 高频问题有固定链接可回复。
- 新贡献者能找到低风险入口。

## 协作边界

为了让公开路线图便于协作者执行，本页只记录已经适合公开讨论和拆分 PR 的方向。还没有验证的商业化设想、定价、内部优先级和私聊反馈，不放进公开仓库。

| 当前边界 | 原因 | 后续条件 |
| --- | --- | --- |
| 不引入复杂后台 | Markdown 足够管理早期计划和案例 | Showcase 数量多到维护困难 |
| 不做大规模改版 | 当前最大问题是入口和路径 | 新手路径和案例飞轮跑通后 |
| 不扩大 PR 范围 | 小改动更容易审查和回滚 | 需要 RFC 的大功能另开讨论 |

## 当前推进顺序

先做最少文件的连续改动：

1. 新增本路线图，并挂到文档站。
2. 重写 `README_EN.md`。
3. 清理 `docs/user-guide/deploy-vercel.md` 的旧链接和个人化措辞。
4. 新增 `docs/user-guide/showcase.md`。
5. 把 Showcase 加到 README、文档首页和 VitePress 导航。

每一步都可以单独提交和回滚，不依赖大改版。

## 下一轮执行清单

当前进入 Phase 3/4 的小步推进，不新增后台，也不一次性补齐所有模板。

| 优先级 | 任务 | 验收 |
| --- | --- | --- |
| P0 | 明确模板页的内容源边界 | 新用户能知道 NotionNext 用 Notion 写内容，GitHub 只负责代码和部署 |
| P1 | 先补博客和知识库两条模板路线 | 每条路线说明适合谁、先改哪几处、推荐主题 |
| P1 | 从最近 Issue / Discussion 抽 3 个重复新手问题 | 每个问题能指向已有文档，或生成一个可拆的小文档任务 |
| P2 | 继续收集 Showcase 站点 | 累计 3-5 个真实站点后，再反向完善模板示例 |
