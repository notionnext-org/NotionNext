# 用户作品墙征集帖草稿

在 GitHub Discussions 发布，用于征集已经上线的 NotionNext 站点。

建议分类：`Show and tell`、`使用问答` 或 `General`。如果 Discussions 没有单独的展示分类，先发到 `General` 并置顶一段时间。

## 标题

```text
【征集】提交你的 NotionNext 站点到用户作品墙
```

## 正文

```md
大家好，

NotionNext 文档站新增了「用户作品墙」：

https://notionnext.tangly1024.com/user-guide/showcase

如果你已经用 NotionNext 搭好了公开网站，欢迎在本帖回复你的站点。我们会把合适的站点整理到 Showcase 页面，让更多人看到社区成员的作品，也帮助新用户按真实案例选择主题。

### 可以提交哪些站点？

- 个人博客
- 作品集 / 个人品牌站
- 知识库 / 文档站
- 产品官网 / SaaS 落地页
- 导航站 / 资源聚合站
- 其他使用 NotionNext 搭建的公开站点

### 回复格式

请按这个格式回复：

| 字段 | 内容 |
| --- | --- |
| 站点名 | 你的站点名称 |
| 站点链接 | https://example.com |
| 用途 | 博客 / 作品集 / 知识库 / 产品官网 / 导航站等 |
| 主题 | 使用的 NotionNext 主题 ID，例如 `simple`、`gitbook`、`starter` |
| 提交人 | GitHub 用户名或站点作者名 |

也可以直接用一行格式：

```md
| [站点名](https://example.com) | 个人博客 | simple | @yourname |
```

### 收录规则

- 站点需要公开可访问。
- 内容需要合法，并与 NotionNext 使用场景相关。
- 失效链接、违法内容、明显无关内容会被移除。
- 如果你后续换主题、换域名或不想继续展示，可以在本帖回复更新。

感谢每一位愿意展示站点的朋友。真实案例会让后来者少走很多弯路。
```

## 发布后维护

发布后建议把链接补到 `docs/user-guide/showcase.md` 的提交说明里，方便新用户直接跳转到征集帖。
