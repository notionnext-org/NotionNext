# 场景模板入口

如果你还不知道从哪种站点开始，先按目标选择模板路线。当前先复用官方 Notion 基础模板，再通过主题和少量配置变成不同类型的网站。

官方基础模板：[Notion Blog](https://tanghh.notion.site/02ab3b8678004aa69e9e415905ef32a5)

## 按目标选择

| 目标 | 推荐主题 | 先改什么 |
| --- | --- | --- |
| 个人博客 | `simple`、`hexo`、`next` | 站点标题、作者信息、文章分类、菜单 |
| 知识库 / 文档站 | `gitbook`、`claude` | 菜单层级、文档分类、首页说明 |
| 作品集 / 个人品牌 | `proxio`、`opc`、`starter` | 个人介绍、作品案例、联系方式 |
| 产品官网 / SaaS 落地页 | `starter`、`landing`、`commerce` | 产品标题、功能区块、价格或 CTA |
| 导航站 / 资源聚合 | `nav` | 链接分类、资源描述、导航菜单 |

## 最小上线步骤

1. 复制官方基础模板。
2. 按 [Vercel 部署](./deploy-vercel.md) 完成第一次上线。
3. 在 [主题全览](./themes/THEMES_CATALOG.md) 中选择目标主题。
4. 只修改站点名称、菜单、首页说明和 3-5 篇示例内容。
5. 上线后把站点提交到 [用户作品墙](./showcase.md)。

先不要一次打开所有插件。评论、统计、搜索、广告、邮件订阅都可以等站点跑通后再补。
