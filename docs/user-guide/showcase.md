# 用户作品墙

这里收集使用 NotionNext 搭建的真实站点，帮助新用户按场景选择主题，也让更多人看到社区成员的作品。

## 作品征集活动

如果你已经用 NotionNext 搭好了网站，欢迎把站点提交到这里。

提交作品可以帮助：

- 让更多人看到你的博客、作品集、知识库、产品官网或导航站。
- 帮助新用户参考真实案例，少在主题选择上反复试错。
- 让维护者知道哪些主题和场景被真实使用，后续优先补文档、截图和模板。

无需写长文，提供站点链接和使用主题即可。

## 如何提交

在 [用户作品征集帖](https://github.com/notionnext-org/NotionNext/discussions/4319) 回复，或直接提交文档 PR 修改本页，提供以下信息即可：

| 字段 | 说明 |
| --- | --- |
| 站点名 | 公开展示的名称 |
| 站点链接 | 可访问的公开 URL |
| 用途 | 博客、作品集、知识库、产品官网、导航站等 |
| 主题 | 使用的 NotionNext 主题 ID，例如 `simple`、`gitbook`、`starter` |
| 提交人 | GitHub 用户名或站点作者名 |

## 推荐格式

```md
| [站点名](https://example.com) | 个人博客 | simple | @yourname |
```

只收录公开、合法、能正常访问的站点。维护者可移除失效链接、违法内容或明显与 NotionNext 无关的提交。
