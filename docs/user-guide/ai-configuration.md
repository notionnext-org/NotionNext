# 使用 AI 配置 NotionNext

可以把手册地址和目标交给支持网页读取及相关操作工具的 AI，例如：

```text
请参考 https://notionnext.tangly1024.com/，帮我在我的 NotionNext 站点配置 NotionComments。先确认站点、部署方式和可用权限，按照适用版本的手册执行；完成后验证并说明结果。
```

AI 可从 [机器可读索引](/llms.txt) 找到文档。提供地址能让 AI 阅读手册，但不会自动授予 Notion、GitHub 或部署平台权限；登录、授权和验证码可能需要你配合。不要把密钥粘贴到公开聊天或提交到仓库。

## 给 AI 的执行要求

1. 确认用户的目标、站点及当前部署方式；读取与用户实际版本匹配的文档和现有配置。已有信息可从工具获取时，不必重复询问。
2. 根据目标检查必要的工具和授权。无法登录、缺少权限或遇到验证码时，说明具体需要用户完成的操作。
3. 使用对应教程中的配置项和权限要求；先确认现有配置，避免覆盖其他设置。密钥只保存在用户授权的安全配置位置，不放进前端变量、仓库、日志或公开回复。
4. 对用户授权的目标执行修改；需要重新部署的按对应平台流程部署。完成后实际检查功能，并报告已验证结果、未完成步骤及原因。
5. 对免费额度、付费服务、公开发布等会影响用户账户的选择，先确认用户目标与授权；不要推断不存在的账号或工具权限。

AI 的能力取决于它能访问哪些工具和账号。只有阅读网页能力的 AI 可以给出操作步骤，但无法替用户修改平台配置。
